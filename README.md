# deepfake-detection-model
A machine learning project intended to detect AI-generated faces from image-level signals.

The project started from the Kaggle [Deepfake Detection Dataset 2026](https://www.kaggle.com/datasets/chuneeb/deepfake-detection-dataset-2026). An audit showed that none of its "fake" images are AI-generated and that its metadata labels are unreliable (see [`01_explore.ipynb`](01_explore.ipynb)). We kept its real Unsplash photos and replaced the fakes with faces generated by StyleGAN3 (see [`02_build_dataset.ipynb`](02_build_dataset.ipynb)).

## Getting the data
Image files are too large for git, so `data/` is listed in `.gitignore`.

**For modeling and analysis**, you only need the processed images:
1. Download `processed` from the team's shared Google Drive folder `deepfake_project`.
2. Unzip it so the images are at `data/processed/reals/` and `data/processed/fakes/`.

The paths in `manifest.csv` are relative to the repository root, so they work as soon as the folder is in place. Run notebooks from the repository root.

**To rebuild the dataset from scratch:**
1. Download the CSV from the Kaggle dataset page and save it as `data/deepfake.csv`.
2. Download `fakes_512` from the shared Drive folder and save it as `data/fakes/`.
3. Run `02_build_dataset.ipynb` from top to bottom. It downloads the real photos, crops and aligns all faces, and writes `manifest.csv`. The results are identical every run.

## manifest.csv
| Column | Values |
|---|---|
| `path` | Image location, e.g. `data/processed/reals/photo-...jpg` |
| `label` | `real` or `fake` |
| `source` | `unsplash` or `stylegan3-t-ffhq` |
| `label_numeric` | **fake = 1, real = 0** (the original Kaggle CSV used REAL = 1) |
| `split` | `train`, `val` or `test` |

| Split | Fake | Real |
|---|---|---|
| train | 560 | 560 |
| val | 107 | 107 |
| test | 119 | 119 |

- Use this split as is, so every result in the project is measured on the same test set. Use `val` for tuning and model choices, and evaluate on `test` only once, at the end.
- Many Unsplash photos come in series from the same photo shoot. The split keeps each series within a single split, so near-identical photos never appear in both training and test.

## Deepfake image generation method
- Model: StyleGAN3-T, pretrained on FFHQ at 1024×1024 (NVIDIA)
- Truncation: 0.7
- Seeds: 0-2799
- Generated on Google Colab (T4 GPU)
- Resized to 512×512 with Lanczos and saved as PNG
- The custom CUDA plugins were disabled and the plain-PyTorch versions used. The images are the same, it's just slower.

## Preprocessing
Real and fake images go through the same pipeline, so framing, size and file format can't give away the label:
- Face detection with OpenCV YuNet; the largest face in each image is used
- Rotated so the eyes are level, then cropped to a square around the face (2.6 × the distance between the eyes)
- Dropped if no face is found, the crop would need enlarging, the crop runs off the photo, or the image is grayscale (no fakes are grayscale)
- Resized to 224×224 and saved as JPEG quality 90

Only 786 of the 2,349 real photos passed, so 786 of the 2,797 usable fakes were randomly sampled to balance the classes.
